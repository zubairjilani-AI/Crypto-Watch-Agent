# Crypto Watch Agent

## My Question
Which of my three coins (BTC, ETH, SOL) is showing an unusual volatility spike or drawdown compared to its 30-day average?

## Watchlist
- BTC (Bitcoin)

## How to Run
1. Add your `GROQ_API_KEY` to GitHub Secrets.
2. Run the workflow from the Actions tab.
